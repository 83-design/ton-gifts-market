# TON Gifts Market

Премиальный Telegram Mini App маркетплейс NFT-подарков в стиле Portals и Fragment.

## Возможности

- **Живое звездное небо** (`<StarfieldBackground />`): 3-слойный Canvas параллакс в 60 FPS на `#050507` с темно-бордовой дымкой (строго без неона).
- **Маркетплейс**: сетка 2×N, фильтры по коллекции, редкости и цене, сортировка, нативные Bottom Sheets.
- **Продать (Sell Flow)**: инвентарь, пошаговый мастер выставления лота с расчётом комиссии 5%, изменение цены и снятие с продажи.
- **TON Connect 2.0 + GRAM**: подключение кошельков (Tonkeeper, Telegram Wallet, MyTonWallet), пополнение с уникальным memo, покупка с внутреннего баланса или напрямую, заявки на вывод.
- **Активность и Профиль**: живая лента сделок, статистика, реферальная программа, история транзакций.
- **Telegram-бот**: уведомления на `grammY`.

## Быстрый старт

```bash
# 1. Установка зависимостей
npm install

# 2. Настройка окружения
cp .env.example .env

# 3. Инициализация SQLite БД и загрузка 15 сид-подарков
npm run db:setup

# 4. Запуск Next.js
npm run dev

# 5. (Опционально) Запуск бота в отдельном терминале
npm run bot
```
